## 🚀 How to Deploy on Vercel (Easiest & Free - Takes 2 Minutes)

### Method 1: Deploy via GitHub (Recommended)
1. Unzip `imran-promth-website.zip`.
2. Go to [GitHub.com](https://github.com) and click **New Repository** (e.g. `imran-promth-website`).
3. In your project folder, open terminal and run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Imran Promth Studio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/imran-promth-website.git
   git push -u origin main
   ```
4. Go to [Vercel.com](https://vercel.com) and click **"Add New Project"**.
5. Import your GitHub repository `imran-promth-website`.
6. Click **Deploy**! (Vercel will build and give you a live URL like `https://imran-promth.vercel.app` in 45 seconds).

### Method 2: Deploy via Vercel CLI (Direct)
1. In the project folder, run:
   ```bash
   npx vercel
   ```
2. Follow the 3 prompts and your website will be live instantly!
